# 🍕 Pizza Sales Dashboard — Power BI

## 📋 Description
Dashboard interactif d'analyse des ventes d'une pizzeria.
Analyse complète des KPIs, tendances et performance des produits.

## 📊 Pages du dashboard

### Page 1 — Home
![Dashboard Home](dashboard_home.png)
- Total Revenue : 817.86K
- Average Order Value : 38.31
- Total Pizzas Sold : 50K
- Total Orders : 21K
- Tendances journalières et horaires
- Répartition des ventes par catégorie et taille

### Page 2 — Top & Bottom Pizzas
![Top Bottom](dashboard_top_bottom.png)
- Top 5 meilleures ventes
- Bottom 5 pires ventes

## 💡 Insights clés
- Jours les plus chargés : **Jeudi, Vendredi et Samedi**
- Heures de pointe : **12h-13h et 17h-18h**
- Catégorie la plus vendue : **Classic (14 888 pizzas)**
- Taille la plus populaire : **Large (45.89%)**

## 🛠️ Technologies
- Power BI Desktop
- DAX (mesures calculées)
- Power Query (transformation des données)
